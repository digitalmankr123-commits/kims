# 가사 템플릿

## 1. Claude 요청문 (복사해서 주제만 바꾸기)

```
수노용 가사를 써 줘.
- 주제: [예: 퇴직 후 첫 아침]
- 분위기: [예: 담담하고 따뜻하게]
- 장르: [styles.md 번호, 예: D3]
- 화자: [예: 60대 남성]
- 길이: 3분 30초 안팎
조건: 구조 태그([Verse] 등) 포함, 후렴은 쉽게 따라 부를 수 있게 반복,
한 줄 10~14자 내외, 중년이 공감할 구체적 장면(사물·장소) 넣기.
결과: 제목 후보 3개 + 가사 + 추천 스타일 프롬프트(영문).
```

## 2. 표준 구조 (3분 30초 안팎)

```
[Intro]

[Verse 1]
(장면 묘사 4줄 — 언제, 어디서, 무엇을)

[Pre-Chorus]
(감정이 올라가는 2줄)

[Chorus]
(핵심 메시지 4줄 — 제목 문구 포함)

[Verse 2]
(시간이 흐른 장면 4줄)

[Pre-Chorus]

[Chorus]

[Bridge]
(관점 전환 2~4줄 — 고백, 깨달음)

[Chorus]
(마지막 후렴 — 한 줄 바꿔 여운)

[Outro]
(제목 문구 반복 1~2줄)

[End]
```

## 3. 짧은 구조 (쇼츠용 1분 안팎)

```
[Intro]
[Chorus]
[Verse]
[Chorus]
[End]
```

## 4. 자주 쓰는 태그

| 태그 | 효과 |
|---|---|
| `[Intro]` `[Outro]` `[End]` | 시작·끝 정리. `[End]`가 없으면 곡이 길게 늘어질 수 있음 |
| `[Instrumental]` `[Guitar Solo]` `[Sax Solo]` | 간주 |
| `[Male Vocal]` `[Female Vocal]` `[Duet]` | 파트별 보컬 지정 |
| `[Whisper]` `[Spoken]` | 속삭임·대사 |
| `[Fade Out]` | 서서히 끝내기 |

> 태그 인식은 수노 버전마다 다를 수 있습니다(확인 필요). 잘 안 먹히는 태그는 `song-log.md` 메모에 남겨 두세요.

## 5. 발음 팁

- 수노가 잘못 읽는 단어는 **소리 나는 대로** 적기 (예: `닭` → `닥`, 숫자는 한글로 `칠십 년대`).
- 영어 섞을 때는 한 줄에 한 단어 정도만.
- 괄호 `( )` 안 내용은 코러스·추임새로 불리는 경우가 많음.
