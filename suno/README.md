# 수노(Suno) 작업 키트 — 민수대장TV

중년 대상 음악을 수노로 만들고 유튜브에 올리는 반복 작업을 **복사·붙여넣기**로 줄이기 위한 모음입니다.

## 파일 구성

| 파일 | 용도 | 쓰는 시점 |
|---|---|---|
| [styles.md](styles.md) | 장르·분위기별 스타일 프롬프트 | 수노 `Style of Music` 칸 |
| [lyrics-template.md](lyrics-template.md) | 구조 태그 가사 템플릿 + Claude 요청문 | 수노 `Lyrics` 칸 |
| [song-log.md](song-log.md) | 곡별 기록 양식 | 생성 직후 |
| [youtube-template.md](youtube-template.md) | 제목·설명란·태그·고정댓글 템플릿 | 업로드 시 |

## 1곡 작업 흐름 (목표 30분)

1. **주제·분위기 정하기** (2분) — 예: "퇴직 후 첫 아침, 담담하고 따뜻하게"
2. **가사 받기** (3분) — `lyrics-template.md`의 *Claude 요청문*에 주제만 바꿔 붙여넣기
3. **스타일 고르기** (1분) — `styles.md`에서 번호 하나 복사
4. **수노 생성** (10분) — Custom 모드, 2~4회 생성 후 1곡 선택
5. **기록** (2분) — `song-log.md` 표에 1줄 추가
6. **업로드** (10분) — `youtube-template.md`의 빈칸만 채우기

## 기본 원칙

- 스타일 칸에 **실존 가수·곡 이름은 넣지 않습니다** (수노가 거부하거나 저작권 문제 소지).
- 상업적 이용(유튜브 수익화)은 **수노 유료 플랜에서 생성한 곡**만 사용 — 최신 약관 확인 필요.
- 유튜브 AI 생성 콘텐츠 표시 정책은 수시로 바뀌므로 업로드 화면의 "변경된 콘텐츠" 항목 확인 필요.
